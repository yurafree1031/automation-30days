# 問い合わせが来た瞬間、担当者のスマホに通知が飛ぶ


## Before / After

| | Before | After |
|---|---|---|
| 気づく | 誰かが回答シートを開くまで気づかない | 届いた瞬間に、担当者のスマホにメールが届く |
| 担当者に伝える | 内容を見て、口頭やメールで伝える | 問い合わせの種類から、決めておいた担当者に自動で届く |
| 返事をするまで | 内容を見て、お客様のアドレスを写して、メールを書く | メールの「対応を始める」→「メールを書く」の2回で、お客様あてのメールが開く。一覧も「対応済み」になる |
| 手を付けたか | 各自の記憶とメールで管理 | 一覧の「状態」が 未対応（赤）・対応済み（緑）で、ひと目で分かる |
| 忘れていたとき | 誰も気づかない | 未対応のまま日がたつと、毎週、担当者にリマインドが届く |
| 止まったとき | 気づかない | 管理者にメールが届く |

## 毎日の使い方

1. お客様がフォームから問い合わせを送ると、「問い合わせ一覧」シートの一番下に行が入り、担当者にメールが届きます
   - メールには、受付日時と問い合わせの内容、一覧を開くリンクがあります
2. メールの「対応を始める」を押します
   - 一覧の「状態」が「対応済み」（緑）になります
   - 出てきた画面の「メールを書く」を押すと、Gmail で、お客様あてのメール（宛先・件名・書き出しが入ったもの）が開きます。そのまま返事を書いて送ってください
   - お客様のメールアドレスがない問い合わせ（電話番号だけ、など）は、「対応済み」になるだけです。電話などで連絡してください
   - 通知のメールにそのまま返信すると、お客様ではなく社内（送信元）に届きます
   - 一覧の「状態」のセルで「対応済み」を選んでも同じです。「対応済み」は「やり取りを始めた」という意味で、終わったかどうかは管理しません
3. 「未対応」のまま日がたつと、毎週（初めは月曜9時）、自分の担当の未対応の問い合わせ（日時・名前・メールアドレス・種類）の一覧がメールで届きます。届いていた通知メールの「対応を始める」から返事をしてください
4. 必要なら「メモ」（薄い青の列）に、対応の内容を書きます

### 見かた

| 色・表示 | 意味 |
|---|---|
| 「状態」が赤 | 未対応。誰もまだお客様とのやり取りを始めていない |
| 「状態」が緑 | 対応済み。担当者がやり取りを始めた |
| 行全体が赤 | 担当者にメールを送れなかった問い合わせ。「確認事項」に理由があります |
| 行全体が黄色 | お客様が、送ったあとで回答を直した問い合わせ。中身は直したあとのものです。確かめたら「確認事項」の文を消すと、色が戻ります |
| 「通知」が「送信済み」 | 担当者にメールを送った |
| 一覧の上の赤い帯 | 自動の処理で問題が起きた。管理者にもメールで知らせています |

一覧の1〜4行目（説明・帯・見出し）は、ツールが使います。消そうとすると警告が出ます。

## 初めて使うとき

担当者の人がすることは、2つだけです。

1. 管理者から共有されたスプレッドシートを、一度開く（メールのリンクから開けるか確かめる）
2. 通知のメールが迷惑メールに入らないよう、送信元のアドレスを連絡先に入れておく

管理者の人は、「管理者向け → 導入のしかた」を先に済ませてください。

## うまくいかないとき

| 困っていること | すること |
|---|---|
| 行全体が赤い | 「確認事項」の文のとおりに直してから、メニュー「問い合わせ管理 → 通知を送り直す」を押す。送れると赤が消えます |
| 「担当者が決まっていません」と出る | 「担当者」シートに、その答えの人か「（それ以外）」の人のメールアドレスを書いてから、「通知を送り直す」を押す |
| 「担当者」シートの行が黄色い | 右の「確認事項」のとおりに直す（答えがフォームの選択肢にない、など）。黄色の行の人には、メールが届きません |
| 「残り ○件 は数分後に自動で送ります」と出る | 待つだけで大丈夫です。数分後に続きが送られます |
| メールが届かない | 迷惑メールのフォルダを見る。一覧の「通知」が「送信済み」なら、メールは送られています |
| メールのリンクから一覧を開けない | 管理者に、スプレッドシートを共有してもらう |
| 「状態」に好きな言葉を入れたい | 「未対応・対応済み」から選ぶ決まりです。補足は「メモ」に書いてください |
| 「対応を始める」を押したら「リンクが正しくありません」と出た | 一覧の「状態」を「対応済み」にしてください |
| 間違えて「対応を始める」を押した | 一覧の「状態」を「未対応」に戻してください |
| 赤い行の「確認事項」を消したい | 消すと赤が消えますが、メールは送られないままです（「通知」は「未送信」のまま。次に問い合わせが届いたとき、もう一度送ろうとします） |
| 一覧の上に赤い帯が出ている | 管理者に連絡する（管理者にはメールでも届いています） |

## 管理者向け

### 導入のしかた

1. フォームの回答先を、このスプレッドシートにする
   - フォームの編集画面の「回答」タブ →「スプレッドシートにリンク」→ このスプレッドシートを選ぶ
   - すでに回答がたまっているフォームでも使えます。回答シート（「フォームの回答 1」）はそのまま残り、ツールからは変えません。**回答シートは消さないでください**（フォームとのつながりが切れ、通知が止まります）
2. このスプレッドシートを開き直す。メニュー「問い合わせ管理」と、「問い合わせ一覧」「担当者」シートができます
3. 「担当者」シートの上の設定を書く
   - **担当者を決める質問**：初めは「お問い合わせの種類」。違う名前なら、手順4のあとに、フォームの質問から選び直します
   - **管理者のメールアドレス**：エラーが起きたとき・担当者に送れなかったときに、ここへメールが届きます（書かないと、通知を始められません）
4. メニュー「問い合わせ管理 → 通知を始める（管理者）」を押す
   - 押す人は、**フォームの編集者**である必要があります
   - 初めてのときは、権限の確認画面が出ます。「続行」→ 自分のアカウントを選ぶ →「許可」を押してください（「このアプリは Google で確認されていません」と出たら、「詳細」→「（プロジェクト名）に移動」）
   - 通知のメールは、**ここで押した人のGmailから送られます**。担当者が替わっても残る、会社の共用アカウントで押してください
   - 押したあとに届いた問い合わせから、一覧に入ります。それより前の回答は取り込みません
   - 担当者を決める質問を選び直したら、もう一度「通知を始める」を押すと、選択肢が「答え」の列に入ります
5. 「担当者」シートの表に、知らせる人を書く
   - 「答え」の列には、フォームの選択肢が入っています（選択肢から選ぶこともできます）。その右に名前とメールアドレスを書きます
   - 1つの答えに2人以上知らせるときは、同じ答えの行を足します
   - どの答えにも当てはまらないとき（フォームに選択肢を足した、など）は、「（それ以外）」の人に届きます。必ず誰かを書いてください
6. スプレッドシートを、担当者全員に「編集者」として共有する（右上の「共有」）。共有しないと、担当者がメールのリンクから一覧を開けません（「対応を始める」ボタンは、共有しなくても使えます）
7. 「対応を始める」ボタンを使えるようにする（ウェブアプリとして公開する）
   - Apps Script のエディタで「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 「次のユーザーとして実行」は「自分」、「アクセスできるユーザー」は「全員」にして「デプロイ」
   - 出てきた「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）をコピーする
   - 「担当者」シートの「ボタンのURL」に、コピーしたURLを貼る
   - あとでコードを直したときは、「デプロイ」→「デプロイを管理」→ 鉛筆の「編集」→ バージョン「新バージョン」→「デプロイ」で更新する。この方法ならURLは変わらない。「新しいデプロイ」で公開し直したときと、スプレッドシートをコピーしたときはURLが変わるので、貼り直す
   - 「全員」にするのは、担当者がスマホでログインせずに押せるようにするためです。リンクには、このツールが作った合言葉が付いていて、番号を書き換えたリンクでは状態を変えられません
   - 公開しないときは、メールにボタンが出ず、「一覧の状態を対応済みにしてください」と書かれます
8. フォームから試しに1件送り、一覧に入ってメールが届くこと、「対応を始める」で「対応済み」になることを確かめる

### 通知を止める・再開する

- メニュー「問い合わせ管理 → 通知を止める（管理者）」で止まります。止めている間に届いた問い合わせは、一覧に入らず、担当者にも届きません
- 「通知を始める（管理者）」で再開します。止めていた間に届いた問い合わせの件数が出るので、「OK」を押すと、一覧に入って担当者に送られます

### 送信元を替えるとき

新しい送信元のアカウントで「通知を始める」を押します。「送信元を替えますか？」と出るので、「OK」を押してください。前のアカウントがまだ使えるなら、先にそのアカウントで「通知を止める」を押しておくと、前のアカウントの自動の処理がきれいに外れます（押さなくても、前のアカウントからは送られません）。

### フォームの質問を変えたとき

- 質問を足すと、次に回答が届いたときに、一覧の「メモ」の左に列が足されます
- 質問の名前を変えると、新しい名前の列が足されます（前の列は残ります。要らなければ消してください）
- 担当者を決める質問の名前を変えたときは、「担当者」シートの「担当者を決める質問」を選び直してください。選び直すまでは、すべて「（それ以外）」の人に届き、管理者にメール（E16）が届きます
- 一覧の列は、並べ替えても、使わない列を消しても動きます（「受付番号」「受付日時」「状態」「担当者」「メモ」「通知」「確認事項」は、消すと一番右に作り直されます）

### 自動で動いているもの

| いつ | 何をするか |
|---|---|
| 問い合わせが届いたとき | 一覧に入れて、担当者に送る |
| 時間切れで残りがあるとき（数百件たまっていたとき、など） | 5分後に続きを送る |
| 毎朝8時 | 取りこぼした問い合わせがないか確かめて取り込む。送れていない問い合わせ（赤い行）があれば、管理者にメールで知らせる |
| 毎週（初めは月曜9時） | 決めた日数より前に受け付けて「未対応」のままの問い合わせを、担当者ごとに1通で知らせる。管理者には担当者ごとの件数を送る（送れなかった赤い行は、毎朝の知らせに任せて載せない） |

自動の処理で起きたエラーは、管理者にメールで届き、「問い合わせ一覧」の上に赤い帯でも出ます。同じエラーのメールは1日1通までです。次にうまく動くと、帯は消えます。

### メールの送信数の上限

Googleのメールの送信数には、1日の上限があります（個人のGoogleアカウントは1日100人、Google Workspace は1,500人。1通を2人に送ると2人と数え、管理者への知らせも数えます）。上限に達すると、その行が赤くなって送るのを止め、残りは「未送信」のまま残ります。このときは管理者へのメールも送れないので、一覧の上の赤い帯と、Googleからの失敗のお知らせ（「通知を始める」を押した人に届く）で知らせます。24時間たったら「通知を送り直す」を押してください。

### エラー番号の一覧

| 番号 | 内容 | 直し方 |
|---|---|---|
| E11 | このスプレッドシートにフォームがつながっていない | 「導入のしかた」の1をする。回答シートを消したときにも出ます |
| E12 | メールの1日の送信数の上限に達した | 24時間たってから「通知を送り直す」を押す。毎日のように出るなら、Google Workspace のアカウントで「通知を始める」を押し直す |
| E13 | メールを送れない（そのほかの理由） | Apps Script の「実行数」でエラーの内容を見る。分からなければ製作者に連絡する |
| E14 | フォームを開けない | フォームが消されていないか、「通知を始める」を押した人がフォームの編集者か確かめる |
| E15 | シートの見出しの行が見つからない | 見出しの「受付番号」（担当者シートは「答え」）を消すか書き換えると出ます。「編集 → 元に戻す」か「ファイル → 変更履歴」で戻す |
| E16 | 担当者を決める質問が、フォームにない | 「担当者」シートの「担当者を決める質問」を、フォームの質問から選び直す |
| E99 | 想定外のエラー | 製作者に連絡する（Apps Script の「実行数」のログを添えて） |

### 変えられる設定

| 設定 | 場所 |
|---|---|
| 知らせる人 | 「担当者」シートの表 |
| 担当者を決める質問 | 「担当者」シートの「担当者を決める質問」 |
| エラーを知らせる人 | 「担当者」シートの「管理者のメールアドレス」 |
| リマインドの曜日・時刻 | 「担当者」シートの「リマインドの曜日」「リマインドの時刻」。変えたら「通知を始める」を押し直す。「しない」で送らない |
| リマインドに載せる日数 | 「担当者」シートの「リマインドに載せる日数」（初めは3日） |
| 「対応を始める」ボタンの行き先 | 「担当者」シートの「ボタンのURL」（ウェブアプリとして公開したときのURL。空欄ならボタンを出さない） |

### 中で覚えていること

どの回答まで一覧に取り込んだか、次の受付番号、送信元のアカウント、止めているかどうかは、Apps Script の「プロジェクトの設定 → スクリプト プロパティ」に残しています。一覧の行を消しても、同じ回答が2回入ることはありません。これらは書き換えないでください。
一覧には、回答ごとの番号（「回答ID」）の列が隠してあります。お客様が回答を直したときに、同じ問い合わせだと分かるようにするためです。消さないでください。

## 使った技術

- Google Apps Script（フォーム送信と時間のトリガー、FormApp で回答を読む、MailApp でメールを送る、ウェブアプリで「対応を始める」ボタン）
- スプレッドシートの条件付き書式（状態の色）、入力規則（状態・答え・質問の選択肢、メールアドレスの形）、保護（見出しの行を消すと警告）
- LockService（同時に届いた回答を1件ずつ取り込み、同じ通知を2回送らない）
