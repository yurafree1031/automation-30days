# テストケース（アンケート集計のデモ）

手元のテストは `node --test tests/*.test.js`（デモのフォルダで実行）。GASの部品は偽物（`lib/gas/tests/fake-gas.js` と `tests/helper.js`）。
ブラウザのテストは、アプリ内のブラウザでスプレッドシートを開いて確かめる。
