# アンケートの集計が、毎週月曜の朝にメールで届く


## Before / After

| | Before | After |
|---|---|---|
| 集計する | 店長が週に1回、回答シートを開いて、平均や件数を数える | 決めた曜日・時刻に、自動で集計される。誰も数えなくてよい |
| 知らせる | 集計を表にまとめて、メールを書いて送る | 前の週の集計が、オーナーと店長にメールで届く |
| 忙しい週 | 集計が抜ける | 抜けない。回答が0件の週も「0件」と届く |
| 移り変わりを見る | 過去のメールを探して見比べる | 「推移のグラフ」シートで、週ごとの平均点と回答数の移り変わりがひと目で分かる |
| イベントのあとだけ集計する | 締め切ってから、全部の回答を数える | 「1回だけ」にしておくと、フォームの受付が終わったときに、全部の集計が1回だけ届く |
| アンケートを締め切ったとき | 最後の週の分を数え忘れる | 受付が終わったら、最後の分を送って自動で終わる |
| 止まったとき | 気づかない | 管理者にメールが届く。直ると、届かなかった週の分も自動で送る |

## 毎日の使い方

使う人（集計を受け取る人）がすることは、届いたメールを読むだけです。

1. 毎週（初めは月曜9時台）、件名が「【アンケート集計】2026/10/12(月)〜10/18(日)　回答 23件」のメールが届きます
2. メールには、質問ごとに次のものが載っています
   - 段階評価（1〜5点など）：平均と、点数ごとの件数・割合
   - 選択式：選択肢ごとの件数・割合。選択肢にない答え（「その他」の欄）は「その他」にまとめます
   - 複数選択：選択肢ごとの件数と、回答した人のうち選んだ人の割合
   - 記述式（ご意見など）：記入された件数だけ。中身は、メールの下の「回答の一覧を開く」から見られます
3. 移り変わりを見たいときは、スプレッドシートの「推移のグラフ」シートを開きます。期間ごとに、段階評価の平均（折れ線）、選択式・複数選択の質問ごとの選択肢の割合（積み上げ棒）、回答数（棒）が並んでいます。記述式はグラフにしません。グラフの元の数字は「集計の履歴」シートにあります

### 見かた（「集計の履歴」シート）

| 色・表示 | 意味 |
|---|---|
| 行の色なし | その期間の集計を、送り先に送った。「送った日時」に送った日時がある |
| 行全体が赤 | その期間の集計を送れなかった。「確認事項」に理由があります。直ると、1時間以内に自動で送り直し、赤が消えます |
| 行全体が黄色 | その期間の集計は、送らないことになった。「確認事項」に「送っていません（理由）」があります（送信を止めていた、など）。管理者が「前回分を今すぐ送る」で送り直せるのは、一番新しい期間の分だけです |
| 一覧の上の赤い帯 | 自動の処理で問題が起きた。管理者にもメールで知らせています |

## 初めて使うとき

使う人がすることは、1つだけです。

1. 集計のメールが迷惑メールに入らないよう、送信元のアドレスを連絡先に入れておく

「集計の履歴」を見る人は、管理者からスプレッドシートを共有してもらってください。
管理者の人は、「管理者向け → 導入のしかた」を先に済ませてください。

## うまくいかないとき

| 困っていること | すること |
|---|---|
| メールが届かない | 迷惑メールのフォルダを見る。「集計の履歴」でその期間の「送った日時」があれば、メールは送られています。赤い行なら、管理者に連絡する |
| 先週の分をもう一度見たい | Gmail で「アンケート集計」を検索する。数字だけなら「集計の履歴」シートでも見られます |
| 平均が「回答なし」になっている | その期間に、その質問に答えた人がいませんでした |
| 「回答の一覧を開く」で開けない | 管理者に、スプレッドシートを共有してもらう |
| 一覧の上に赤い帯が出ている | 管理者に連絡する（管理者にはメールでも届いています） |

## 管理者向け

### 導入のしかた

1. フォームの回答先を、このスプレッドシートにする
   - フォームの編集画面の「回答」タブ →「スプレッドシートにリンク」→ このスプレッドシートを選ぶ
   - すでに回答がたまっているフォームでも使えます。回答のシート（「フォームの回答 1」など）はそのまま残り、ツールからは変えません。**回答のシートは消さないでください**（集計できなくなります）
2. このスプレッドシートを開き直す。メニュー「アンケート集計」と、「設定」「集計の履歴」シートができます（「推移のグラフ」シートは、初めて集計を送ったときにできます）
3. 「設定」シートの薄い青のセルを書く
   - **送り先**：集計を受け取る人のメールアドレス。複数のときは、改行かカンマで区切ります
   - **管理者のメールアドレス**：自動の送信でエラーが起きたとき、ここへメールが届きます
   - **送る間隔・曜日・時刻**：初めは「毎週・月・9時」（毎週月曜9時台に、前の週の月〜日の分）
   - **1回だけ集計するとき**（イベントのあとなど）：「送る間隔」を「1回だけ」にする。フォームの受付が終わったら（終わってから1時間のうちに）、最初の回答からの全部の集計が1回だけ届きます
   - **フォームの受付が終わったとき**：どの間隔でも、最後の分（前に送った期間のあと〜受付が終わるまで）を送って終わります。受付の終わりは、フォームの「回答を受け付ける」をオフにしたときと、フォームで決めた締め切りの日時になったときです（締め切りの日時はツールから読めないので、1時間ごとに受付中かを確かめています）。受付を再開すると、また決まった間隔で送ります
   - 書き方が違うセルは黄色になります。黄色のままだと、送信を始められません
4. メニュー「アンケート集計 → 送信を始める（管理者）」を押す
   - 押す人は、**フォームの編集者**である必要があります。フォームが回答を受け付けていないと、始められません
   - 初めてのときは、権限の確認画面が出ます。「続行」→ 自分のアカウントを選ぶ →「許可」を押してください（「このアプリは Google で確認されていません」と出たら、「詳細」→「（プロジェクト名）に移動」）
   - 集計のメールは、**ここで押した人のGmailから送られます**。担当者が替わっても残る、会社の共用アカウントで押してください
   - 「集計する質問」シートができ、フォームの質問が並びます
   - 押したあとに来る期間から送ります。すでに終わった期間は送りません
   - フォームの回答のシートの列幅を、質問に合わせて広げ、長い答えの列は折り返します（一度整えた列は、あとで幅を変えても戻しません）
5. 「集計する質問」シートで、集計に入れない質問（お名前・メールアドレスなど）の「集計する」のチェックを外す
6. メニュー「アンケート集計 → 前回分を今すぐ送る（管理者）」を押して、送り先にメールが届くこと、「集計の履歴」に1行入ることを確かめる
7. 「集計の履歴」を見る人がいれば、スプレッドシートを共有する（右上の「共有」。見るだけなら「閲覧者」）

### 送信を止める・再開する

- メニュー「アンケート集計 → 送信を止める（管理者）」で止まります。止めている間は、集計のメールが届きません
- 「送信を始める（管理者）」で再開します。止めていた間に終わった期間があると、その数と期間が出ます
  - 「OK」：止めていた間の期間の集計を、まとめて送ります（さかのぼれるのは5期間まで。それより前の期間は「集計の履歴」に黄色い行で残ります）
  - 「いいえ」：送らずに、次の期間から送ります。止めていた間の期間のうち、送れなかった赤い行は黄色い行になります

### 送信元を替えるとき

新しい送信元のアカウントで「送信を始める」を押します。「送信元を替えますか？」と出るので、「OK」を押してください。前のアカウントがまだ使えるなら、先にそのアカウントで「送信を止める」を押しておくと、前のアカウントの自動の処理がきれいに外れます（押さなくても、前のアカウントからは送られません）。

### フォームの質問を変えたとき

- 質問を足すと、次に送るときに「集計する質問」シートに増えます（チェックが入った状態で増えます）
- 質問の名前を変えると、新しい名前の質問として扱います。「集計する」のチェックは付け直してください
- 段階評価の質問を足すと、「集計の履歴」の右に「平均：（質問の名前）」の列が増えます。名前を変えたときも新しい列が増えます（前の列は残ります）

### 自動で動いているもの

| いつ | 何をするか |
|---|---|
| 1時間ごと | 送る時刻を過ぎて、まだ送っていない期間があれば、集計して送る。フォームの受付が終わっていたら、最後の分を送る。「設定」シートの「送信の状態」の、次に送る日時を書き直す |

決まった時刻に動く仕組みにせず、1時間ごとに確かめているのは、次の2つのためです。

- 「設定」シートで間隔や時刻を変えても、押し直さずにそのまま使われる（「送る間隔」「送る曜日」を変えたときは、変えたあとに終わる期間から送ります。変えた直後に、過去の期間の分が何通も届くことはありません）
- 送れなかった期間（送り先の書き間違いなど）を、直ったあとの1時間以内に自動で送り直せる（さかのぼるのは5期間まで。それより前の期間は送らず、黄色い行にします）

このため、メールは決めた時刻ちょうどではなく、その時刻から1時間のうちに届きます。
自動の処理で起きたエラーは、管理者にメールで届き、「集計の履歴」の上に赤い帯でも出ます。同じエラーのメールは1日1通までです。直ったあと、次の1時間ごとの確認で帯は消えます（「設定」シートの間違いは、直した時点で消えます）。
「前回分を今すぐ送る」で送ると、それより前の、送れずに残っていた期間（赤い行）は自動では送らなくなり、黄色い行になります。

### メールの送信数の上限

Googleのメールの送信数には、1日の上限があります（個人のGoogleアカウントは1日100人、Google Workspace は1,500人。1通を5人に送ると5人と数えます）。上限に達すると、その期間は赤い行になり、管理者へのメールも送れないので、「集計の履歴」の上の赤い帯と、Googleからの失敗のお知らせ（「送信を始める」を押した人に届く）で知らせます。上限が戻ると、自動で送り直します。

### エラー番号の一覧

| 番号 | 内容 | 直し方 |
|---|---|---|
| E11 | このスプレッドシートにフォームがつながっていない | 「導入のしかた」の1をする |
| E12 | メールの1日の送信数の上限に達した | 待つだけで、上限が戻ると自動で送ります。毎日のように出るなら、Google Workspace のアカウントで「送信を始める」を押し直す |
| E13 | メールを送れない（そのほかの理由） | 管理者へのメールの「詳しい内容」を見る。「送り先」のアドレスの間違いが多い。分からなければ、そのメールを添えて製作者に連絡する |
| E14 | フォームを開けない | フォームが消されていないか、「送信を始める」を押した人がフォームの編集者か確かめる |
| E15 | フォームの回答のシートが見つからない | 回答のシートを消すと出ます。フォームの「回答」→「スプレッドシートにリンク」で、このスプレッドシートを選び直す（それまでの回答は、フォームに残っているものが新しいシートに入ります） |
| E17 | 「設定」シートの送り先・間隔などが正しくない | 「設定」シートの黄色のセルを直す |
| E99 | 想定外のエラー | 製作者に連絡する（Apps Script の「実行数」のログを添えて） |

### 変えられる設定

| 設定 | 場所 |
|---|---|
| 送り先 | 「設定」シートの「送り先」 |
| エラーを知らせる人 | 「設定」シートの「管理者のメールアドレス」 |
| 送る間隔（毎日・毎週・毎月・1回だけ） | 「設定」シートの「送る間隔」。毎日＝前の日の分、毎月＝毎月1日に前の月の分、1回だけ＝フォームの受付が終わったときに全部の分 |
| いつまで送るか | フォームの締め切り（「回答を受け付ける」のオフ、または締め切りの日時）。受付が終わったら最後の分を送って終わる |
| 送る曜日・時刻 | 「設定」シートの「送る曜日」（毎週のときだけ）「送る時刻」 |
| 集計する質問 | 「集計する質問」シートの「集計する」のチェック |

設定を変えると、「送信の状態」に次に送る日時が出ます。

### 中で覚えていること

どの期間まで送ったか、送信元のアカウント、止めているかどうかは、Apps Script の「プロジェクトの設定 → スクリプト プロパティ」に残しています。「集計の履歴」の行を消しても、同じ期間が2回送られることはありません。これらは書き換えないでください。

## 使った技術

- Google Apps Script（時間のトリガー、FormApp で質問の種類を読む、MailApp でHTMLのメールを送る）
- スプレッドシートの入力規則（間隔・曜日・時刻のプルダウン、集計する質問のチェックボックス）、保護（見出しの行を消すと警告）
- LockService（自動の送信と「前回分を今すぐ送る」が重なっても、同じ集計を2回送らない）
