# 領収書を撮るだけで、経費表が勝手に埋まる


## Before / After

| | Before | After |
|---|---|---|
| 作業 | 領収書を見ながら、日付・店名・金額を1枚ずつ手入力 | 写真をGoogleドライブのフォルダに入れて、ボタンを1回押すだけ |
| 勘定科目 | 毎回自分で判断 | AIが内容から候補を入れる（あとで直せる） |
| 元の画像 | どこにあるか探す | 経費表の各行から画像に飛べる |
| 集計 | 月末に勘定科目ごとに電卓で足す | 月別・四半期別・年度別をプルダウンで切り替えられるグラフが、自動で更新される |

## 毎日の使い方

1. 領収書の写真（JPG・PNG・PDF）を、未処理フォルダに入れる
2. 「実行」シートの「領収書を読み取る」ボタンを押す
3. 画面右下に「記録 5件　エラー 1件　確認 2件」のように結果が出たら、「経費表」シートを確認する
   - 写真は、読み取れなかったものも含めて、処理済みフォルダに自動で移ります。経費表の画像列のリンクから開けます
   - 1回で読み取れるのは4〜5分ぶんです（目安は数十枚）。残りがあるときは通知に枚数が出るので、もう一度押してください
   - 結果は「実行」シートの「前回の結果」にも残ります（通知は20秒で消えます）。実行中にもう一度押しても、同じ写真が二重に記録されることはありません（「別の読み取りが実行中です」と出ます）

ボタンはパソコンのブラウザで使ってください。スマートフォンのスプレッドシートアプリでは、ボタンを押しても動きません。

AIの読み取りは間違えることがあります。特に金額は、画像列のファイル名をクリックして写真を開き、確認してください。

### 集計を見る

「グラフ」シートで、経費を勘定科目ごとに見られます。上の「表示」にあるプルダウン（それぞれの上に「集計の単位」「グラフの種類」「円グラフの期間」と書いてあります）で切り替えます。

| プルダウン | 選べるもの |
|---|---|
| 1つ目（C2） | 月別・四半期別・年度別（年度と四半期は、「設定」シートの「年度の始まりの月」から数えます） |
| 2つ目（D2） | 棒グラフ（期間ごとの推移）・円グラフ（1つの期間の内訳） |
| 3つ目（E2） | 円グラフで見る期間（2026-10、2026年度-Q3 など）。空欄なら、いちばん新しい期間になります。1つ目を切り替えると空欄に戻ります |

グラフの下には集計表もあります。経費表に行が増えたり、手で金額や勘定科目を直したりすると、自動で反映されます（赤い行のように、日付や金額が空の行は数えません）。

薄い青のセルは、入力したり選んだりする場所です。

## 初めて使うとき

### 1. 権限を許可する

ボタンを初めて押す人ごとに、一度だけ権限の確認画面が出ます。立ち会いは不要で、その人自身が次の手順で許可します。

1. 「このアプリは Google で確認されていません」と表示されたら、左下の「詳細」を押す
2. 「（プロジェクト名）（安全ではないページ）に移動」を押す
3. 「許可」を押す

この画面は、自社用に作ったプログラムを初めて動かすときに必ず出るものです。許可する内容は、スプレッドシートへの書き込み、ドライブのフォルダと画像の操作、AIとの通信の3つです。

許可が終わったあと、読み取りが始まらなかったときは、もう一度ボタンを押してください。

### 2. フォルダと年度を設定する

許可が終わると、「経費表」「設定」「店別勘定科目」「グラフ」の4つのシートが自動でできます（「実行」シートは、スプレッドシートを開いたときにできています）。「設定」シートに、使うフォルダのURLを2つ貼ってください（共有ドライブのフォルダも使えます）。

| 項目 | 貼るもの |
|---|---|
| 未処理フォルダのURL | 領収書の写真を入れるフォルダ |
| 処理済みフォルダのURL | 読み取りが終わった写真を移すフォルダ（未処理とは別のフォルダ） |
| 年度の始まりの月 | 決算月の次の月。最初は 4（3月決算）になっています。12月決算なら 1 にします |

フォルダのURLは、Googleドライブでフォルダを開いたときに、ブラウザの上に表示されているアドレスです。あとでフォルダを変えたいときも、ここを貼り替えるだけです。

ボタンを押す人には、**2つのフォルダの両方に、編集の権限**が必要です。閲覧のみの人が押すと、写真を移せずに止まります（管理者向けの通知 `[E06]` が出ます）。

### 3. 勘定科目の候補を確認する（必要なときだけ）

「設定」シートのD列「勘定科目の候補」に、AIが選ぶ勘定科目が並んでいます。AIは、この中から領収書の内容に一番近いものを1つ選びます。会社で使っている勘定科目に合わせて、足したり消したりしてください（1行に1つ。13個までです。グラフに並べられる数の上限です）。経費表と「店別勘定科目」シートの「勘定科目」は、この一覧から選びます。足したい勘定科目も、ここに書きます。

### 4. 店ごとの勘定科目を決める（必要なときだけ）

「この店のレシートは必ずこの勘定科目」と決まっているものは、「店別勘定科目」シートに登録しておくと、AIの判断より優先されます。

| 店名（一部でOK） | 勘定科目 |
|---|---|
| JR東日本 | 旅費交通費 |
| スターバックス | 会議費 |

書き方のルールは、シートの上にも書いてあります。勘定科目は、「設定」シートの候補から選びます。

- レシートに印字されている店名のうち、その店だと分かる部分を書いてください。「スターバックス」と登録すれば、「スターバックス コーヒー 渋谷店」にも当てはまります
- 支店ごとに変えたいときは、空白で区切って支店名も書いてください。「スターバックス 渋谷店」と登録すれば、「スターバックス コーヒー 渋谷店」に当てはまり、「スターバックス」より優先されます
- 略称（スタバ）や短すぎる言葉（店）は使わないでください
- 全角/半角、ひらがな/カタカナ、空白、「株式会社」などの違いは気にしなくて大丈夫です

## うまくいかないとき

結果やエラーは、画面右下に通知で出ます。

- **「確認してください」**：その場で直せる内容です。通知の指示どおりに直して、もう一度押してください（例: フォルダのURLが空、AIが混雑中）
- **経費表の赤い行（通知の「エラー」）**：写真が不鮮明・大きすぎる・領収書ではないなどで、読み取れなかった領収書です。右端の「確認事項」列に直し方が書いてあります。画像列のリンクから写真を見て手で入力するか、行を消して、撮り直した写真を未処理フォルダに入れ直してください
- **経費表の黄色の行（通知の「確認」）**：読み取れたものの、確認が必要な領収書です。「確認事項」列に理由が書いてあります。画像列のリンクから写真を開き、日付・店名・金額が合っているか確認してください
  - 読み取りが不確かです：AIが自信を持てなかった
  - 日付が今日より先／1年以上前です：日付の読み間違いの可能性がある
  - 同じ日付・店名・金額の行が既にあります：同じ領収書を二重に入れていないか。二重なら、片方の行を消してください
  - 店別勘定科目の「○○」が勘定科目の候補にありません：「店別勘定科目」シートの勘定科目を、候補から選び直してください
- **「管理者に連絡してください」**：専門の知識が必要な内容です。通知に出た文章（`[E01]` などの番号を含む）をそのまま管理者に伝えてください。途中で止まったときは、それまでに記録した件数も出ます

赤・黄色の行を確認・修正し終わったら、「確認事項」列の文字を消してください。行の色が元に戻ります。まとめて消したいときは、上のメニュー「操作メニュー → 確認事項を一括クリア」を使ってください。金額が空の赤い行（読み取れなかった領収書）は、手入力するまで目印を残します。

経費表に手で入力するときは、日付は「2026/10/15」の形、金額は数字だけ（例: 1280）で入れてください。それ以外の形は入力できません。

「経費表」シートを間違えて消してしまったときは、上のメニュー「ファイル → 変更履歴」から、消す前の版に戻せます。グラフは、経費表が戻れば自動で集計し直します。

## 管理者向け

### 導入のしかた

1. スプレッドシートを用意し、「拡張機能 → Apps Script」を開いて、次のファイルを同じ名前で貼り付ける
   - `Code.gs`（本体）・`Chart.gs`（グラフ）・`Button.gs`（ボタンの画像）・`AI.gs`（AIの呼び出し）・`Errors.gs`（エラーの種類）
2. 「プロジェクトの設定 → スクリプト プロパティ」に、使うAIの名前のプロパティを追加し、APIキーを貼る
   - Gemini なら `GEMINI_API_KEY`、Claude なら `CLAUDE_API_KEY`、OpenAI なら `OPENAI_API_KEY`。書いたキーのAIを使います
   - 2つ以上書いたときは、`AI_PROVIDER` に使うAI（gemini／claude／openai）も書きます
3. スプレッドシートを開き直すと、ボタンのある「実行」シートができる。あとは「初めて使うとき」の手順どおり
   - ボタンや「グラフ」シートができない、または消してしまったときは、エディタで関数 `ensureRunSheet` を選んで実行する
4. ボタンを押す人全員に、「未処理」「処理済み」の両方のフォルダの編集権限を渡す。初めて押す人は、「初めて使うとき」の権限の確認画面を、自分で許可する

社外に出せない書類を扱う場合は、有料のAPIキーを使ってください。無料枠では、送った内容がAIの会社のサービス改善に使われる場合があります。

### AIの費用の目安

初期のモデル（Gemini 3.8 Flash）で、**領収書100枚あたり50円前後**です（月50〜100枚なら、月に数十円）。2026年10月時点の料金表からの見積もりで、Googleは2027年1月から単価を上げる予定です。実際の金額は、AIの会社の管理画面で確認してください。

### エラー番号の一覧

| 番号 | 通知の内容 | 原因 | 直し方 |
|---|---|---|---|
| E01 | APIキーが設定されていません／使うAIが決められません | スクリプトプロパティに `GEMINI_API_KEY` などのキーがない。キーが2つ以上あるのに `AI_PROVIDER` がない。`AI_PROVIDER` の値が正しくない | 使うAIのキーを追加する。キーが2つ以上なら `AI_PROVIDER` に gemini／claude／openai のどれかを書く |
| E02 | APIキーが正しくありません | APIキーの打ち間違い、削除・無効化されたキー、別のAIのキーを貼った（例: `GEMINI_API_KEY` に Claude のキー） | AIの会社の管理画面でキーが有効か確認し、貼り直す |
| E03 | AIのモデルが使えません | 使っているモデルの提供が終わった | エラー文に出ている推奨モデル名など、今使えるモデル名をスクリプトプロパティ `AI_MODEL` に書く |
| E04 | AIとの通信でエラー（数字） | 上記以外のAIのエラー。画像に原因がある場合は、その画像だけ赤い行になる。E04 で止まるのは、画像が受け付けられない状態が3枚続いたとき | 通知に出たエラー文を確認する。続く場合は、通知の文とApps Scriptの「実行数」のログを添えて、製作者へ連絡する |
| E05 | AIの利用枠の上限に達しています | 前払いの残高がない、利用上限に達した、無料枠の1日の上限や回数の上限に達した | AIの会社の管理画面で、残高・上限・無料枠を確認し、上限を上げるか、上限が戻る翌日以降にもう一度押す |
| E07 | 「…」のフォルダを開けません（E07） | 「設定」シートのURLは正しいが、ボタンを押した人にフォルダが共有されていない。またはフォルダが削除された | フォルダを開き、押した人に編集の権限を渡す。削除されていたら、ゴミ箱から戻すか、新しいフォルダのURLを貼る |
| E06 | 画像を処理済みフォルダに移せません | ボタンを押した人に、未処理・処理済みのフォルダの編集権限がない | 押した人に、2つのフォルダの編集権限を渡す。写真は未処理フォルダに残っているので、渡したあとにもう一度押せばよい |
| E08 | 設定の値が正しくありません | 下の「変えられる設定」のスクリプトプロパティに、数字でない値や範囲の外の値が書かれている | エラー文に出た項目を、範囲の中の数字に直す。分からなければ項目ごと消す（初期値に戻る） |
| E99 | 想定外のエラー | プログラムの不具合、Googleドライブ側の一時的な問題など | Apps Scriptの「実行数」で該当する実行のログを確認する。直らない場合は、通知の文とログを添えて、製作者へ連絡する |

製作者の連絡先は、納品時にお伝えします。

### 変えられる設定

どれも「プロジェクトの設定 → スクリプト プロパティ」で変えられます（コードを書き換える必要はありません）。書かなければ初期値を使います。

| 項目 | 場所 | 内容 |
|---|---|---|
| `GEMINI_API_KEY` / `CLAUDE_API_KEY` / `OPENAI_API_KEY` | スクリプトプロパティ | 使うAIのAPIキー（どれか1つは必須） |
| `AI_PROVIDER` | スクリプトプロパティ | キーを2つ以上書いたときだけ、使うAIを書く（gemini／claude／openai） |
| `AI_MODEL` | スクリプトプロパティ | モデルを変えたいときだけ書く。書かなければ `AI.gs` の `AI_DEFAULT_MODELS` を使う |
| `CONFIDENCE_WARN` / `CONFIDENCE_FAIL` | スクリプトプロパティ | AIの自信度（0〜100）がこれ未満なら黄色／赤の行にする（初期値 90／50）。モデルを変えたときは、精度テストの結果を見て決め直す。日付の形が違う・金額が0以下・店名が空のときは、自信度に関係なく赤になる |
| `TIME_BUDGET_SECONDS` | スクリプトプロパティ | 1回の読み取りに使う秒数（初期値270、30〜300）。GASは1回6分で強制終了するため、これを過ぎたら次の画像に進まずに止める |

勘定科目の候補・年度の始まりの月・フォルダは、「設定」シートで変えます。

## 使った技術

- Google Apps Script（ドライブ・スプレッドシートの操作、画像に関数を割り当てたボタン）
- 生成AIのAPI（Gemini・Claude・OpenAI のどれでも。画像を読み取り、決まった形のJSONで返すよう指定）
